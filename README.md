# Miraz Airlines Website

A responsive, functional front-end prototype for Miraz Airlines.

## Included
- Professional airline-style homepage
- Flight search and filters
- Flight selection
- Passenger details
- Interactive seat map
- Add-ons and dynamic fare calculation
- Mock payment/booking confirmation
- PNR generation
- Local booking persistence
- Manage Booking
- Cancellation/refund demo state
- Online check-in
- Boarding-pass display
- Flight status
- Login modal
- Responsive mobile navigation

## Run
No build step is required for this prototype.

1. Extract the folder.
2. Open `index.html` in a browser.

For the full production system described in the specification, connect the UI to:
- React/Vite/Tailwind
- Node.js/Express REST APIs
- PostgreSQL/MySQL
- JWT authentication and role-based access
- Real payment provider
- Transactional seat locking
- Email/notification service

The current prototype intentionally uses browser localStorage and a mock payment flow so it can run immediately without server setup.
